## Overview

Humphrey is a music discovery web application that maps connections between any artist and a favorite artist through song collaborations.

## Features

- Implemented the platform using Node.js, Express, JavaScript, and MongoDB for scalable backend and efficient data handling.
- Leveraged the "6 degrees of separation" theory.
